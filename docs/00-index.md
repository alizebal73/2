## وضعیت فعلی پروژه
- **مرحله:** UI پروتوتایپ تایید شد (۶ صفحه کامل) — قدم بعدی طبق سند ۰۵: React با MockService، بعد اتصال به هسته بدون بازنویسی
- **قرار مهم:** prototype/index.html = سند طراحی تاییدشده؛ بازنویسی ممنوع؛ کد آینده عیناً همین طراحی را پیاده می‌کند
- **تکنولوژی تاییدشده:** ASP.NET Core + SignalR + SQLite + React (RTL) + WPF (کلاینت فاز ۳)
- **مجموعه کاربر:** ۴۰ کیس + ۱۰ PS5 + ۶ PS4 + ۵ فوتبال‌دستی = ۶۱ ایستگاه

## نکات کلیدی که نباید فراموش شود
- کنسول‌ها (PS5/PS4) و فوتبال‌دستی **کلاینت نمی‌خواهند** — فقط تایمر در داشبورد + آلارم
- کلاینت فقط برای ۴۰ کیس (فاز ۳، اول روی ۲–۳ کیس آزمایشی)
- پول با `long` تومان، تاریخ ذخیره میلادی/نمایش شمسی، موتور هزینه = توابع خالص + تست واحد
- فارسی/RTL در همه UI؛ تاریخ شمسی در همه گزارش‌ها
- سرور = تنها منبع حقیقت؛ بازیابی جلسات باز بعد از قطع برق
- اپراتور نباید برای عملیات پرمصرف بین صفحه‌ها پرش کند (همه‌چیز از کارت ایستگاه)
- پیشروی با Vertical Slice؛ هر هفته نسخه اجرایی؛ Parallel Run بعد از مرحله تسویه

## نقشه UI — وضعیت
- ✅ داشبورد زنده گرید ۶۱ ایستگاه + ۳ حالت نمایش (کارتی/فشرده/لیستی)
- ✅ مشتریان: لیست+پروفایل master-detail، پکیج VIP با لیمیت روزانه
- ✅ بوفه: سبد فروش سریع با هدف جلسه/مستقل
- ✅ گزارش‌ها: نمودار ۷روز/ماه/سال + **بازه دلخواه (از/تاریخ شمسی + ساعت از/تا)** با ۷ میان‌بر (امروز/دیروز/این هفته/ماه جاری/ماه قبل/۹۰ روز/امسال) + ۴ فیلتر (ایستگاه/اپراتور/روش پرداخت/نوع تراکنش) + چاپ گزارش + خروجی اکسل + خلاصه مالی + کارکرد ایستگاه
- ✅ کاربران: نقش صاحب/مدیر/اپراتور + ماتریس دسترسی + شیفت
- ✅ تنظیمات: ۶ پنل سوییچ‌دار
- ✅ شل مشتری (prototype/client.html): لاگین با شناسه، دسکتاپ بازی، منوی راست‌کلیک (تغییر اینترنت/جابه‌جایی شناسه/ورود-خروج/درخواست شارژ/پیام/قفل)، پنل حساب مشتری، تایمر زنده با رنگ هشدار
- ✅ شارژ سریع: دابل‌کلیک روی کارت در حال بازی → مودال مبلغ با دکمه‌های آماده و Enter
- ✅ پالت فرمان اپراتور: Ctrl+K + هات‌کی‌های F2-F9 (شارژ مستقیم/شارژ+بدهی/کسر اعتبار/بوفه/مشتری/شروع جلسه/تمدید/بستن صندوق)
- ✅ صفحه بازی‌ها: تعریف بازی (نام، دسته، مسیر exe، کاور/تریلر، پارامتر، نوع اتصال، مقصد)، اعمال به کلاینت‌ها
- ✅ پنل تنظیمات کلاینت‌ها: انتخاب تک/گروهی، IP/DNS/شماره/آدرس سرور، ری‌استارت/خاموش/ریموت
- ✅ تصمیم معماری: داشبورد در پوسته WebView2 (پنجره تکی مستقل از مرورگر) — در سند ۰۳ ثبت شد
- ✅ صفحه کلاینت‌ها (مستقل): ۴۰ کارت با IP/DNS/یوزر/شبکه/شل + راست‌کلیک هر کیس → ۱۱ اقدام مخصوص همان دستگاه (سوییچ اینترنت ۱↔۲، قطع/وصل، جابه‌جایی/خروج یوزر، ورود با شناسه، پیام، اسکرین‌شات، ری‌استارت شل/ویندوز، خاموش) + دبل‌کلیک → مودال تنظیمات کامل (IP/DNS/سرور/CCBOOT/PXE)
- ✅ انتخاب گروهی کلاینت‌ها: کلیک تکی + Ctrl (تک‌تک) + Shift (بازه) → نوار سبز تعداد انتخاب‌شده‌ها → راست‌کلیک منو برای همه اعمال می‌شود (تست: خروج یوزر روی ۸ کلاینت)
- ✅ مودال بازی: سه انتخاب‌گر جدا (exe / کاور / تریلر) هر کدام با مسیر مستقل + پیش‌نمایش مربعی کاور
- ✅ مشتری: کد کاربری عددی (مثل ۱۰۵۰/۲۰۲۰) جدا از نام و فامیل — ورود کلاینت با کد+رمز؛ جست‌وجوی همه‌فیلدی (کد/نام/فامیل/لقب/موبایل/کد ملی) در F1 و صفحه مشتریان
- ✅ صفحه تعرفه‌ها (مستقل): تعرفه عادی/VIP هر نوع ایستگاه + پکیج‌ها + تعرفه شبانه؛ فیلتر عادی/VIP
- ✅ بازی‌ها: هر بازی می‌تواند مخصوص سیستم‌های VIP یا عادی یا همه باشد
- ✅ صفحه اکانت‌ها (استخر — تحقیق iCafeCloud License Pool): اکانت‌های Steam/Battle.net/Riot/Epic شماره‌گذاری‌شده، وضعیت آزاد/در استفاده/قفل، تخصیص خودکار به جلسه، آزادسازی خودکار، رمزها فقط سرور (هرگز به مشتری)، لاگ کمبود
- ✅ کلاینت: دابل‌کلیک بازی → باکس دو دکمه‌ای «اکانت خودم / اکانت گیم‌نت» → لاگین خودکار از سمت سرور
- ✅ داشبورد: راست‌کلیک هر کارت = منوی کلاینت‌محور (۱۱ اقدام: اینترنت/یوزر/پیام/اسکرین‌شات/ری‌استارت/خاموش/سرویس)؛ کلیک‌چپ روی کارت آزاد/رزرو = مودال شارژ دلخواه
- ✅ کلاینت: قلنک با اسلایدر اندازه لیست؛ ستون چپ = مربع پیش‌نمایش بازی (هاور روی بازی) + دو خط توضیح + کارت تبلیغ زیرش با دکمه بستن و بازگشایی؛ دکمه‌های ورود اپراتور (Alt+F6) و آزادسازی (Alt+F7) در صفحه لاگین (قبل از ورود مشتری)
