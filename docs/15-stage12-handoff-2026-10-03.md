# Stage 12 — Handoff 2026-10-03

## Baseline

Stage 11 is the server-backed Game Catalog + Account Pool/Lease slice. Stage 12 must branch from the latest green `main` head after the final Stage 11 hardening CI run.

## Goal

Turn the Stage 11 data model into a real operational flow where a customer Session on an Agent can acquire, use, and release a GameNet account without exposing secrets to Dashboard and without making Client state authoritative.

## First vertical slice

1. Session → Lease request: authoritative Session identifies Game and Customer/Agent; Client sends references, not truth.
2. Atomic allocation: one free compatible AccountPoolEntry can produce at most one active Lease; concurrency remains server-authoritative.
3. Credential boundary: SecretHash remains server-side; Agent credential delivery is authenticated, short-lived, Lease-bound, and never exposed to Dashboard/browser storage.
4. Lifecycle release: normal Session end releases the Lease; Agent disconnect/recovery has an explicit policy; manual operator release remains a recovery command.
5. Real Game operational data: activeUsers comes from authoritative Session/Agent state; Game status is operationally defined; Apply/Sync becomes a real Agent command only after its contract exists.

## Dependencies to audit before coding

- Session ↔ Game
- Session ↔ CustomerLogin
- Session ↔ AgentDevice/Station
- AccountLease ↔ Session
- AccountLease ↔ AgentDevice
- AccountPoolEntry ↔ allowed games
- Lease state transitions, conflict handling, and recovery

## Security boundary

Never expose raw Secret, SecretHash, or long-lived credential material through Dashboard-facing DTOs or browser storage.

## Required tests

- one account / two concurrent allocations
- valid Session + Agent required for operational allocation
- invalid Session/Agent rejected
- credential retrieval denied outside active Lease boundary
- normal Session end releases Lease
- Agent disconnect/recovery follows defined policy
- duplicate release is safe
- Game active-user count reflects authoritative Session state
- real Apply/Sync command round-trip when enabled

## Non-goals at Stage 12 start

Do not reopen the legacy `GameAccount` model, Stage 10 Client update/rollback architecture, or unrelated Dashboard redesign.

## Definition of Done

**Build → Test → Migration → Server Smoke → Agent/Session/Lease Smoke → Dashboard Browser Smoke** must all be green for the first vertical slice.
